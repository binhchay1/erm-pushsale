# V47 - Modal System Fix

## Scope
Fix toàn bộ modal/dialog trong project đang bị lệch lên trên hoặc lệch trái.

## Root cause
Project đang có nhiều kiểu modal cùng tồn tại:

- Radix dialog: `[data-slot='dialog-content']`, `.ps-modal-surface`, `.ps-sale-modal`.
- Legacy React modal: `.ps-modal-backdrop` + `.ps-modal-card`, `.ps-source-modal`.
- Legacy page modal: `.legacy-modal-layer` + `.legacy-modal-dialog`.
- Report/marketing modal: `.psm-modal-layer`, `.pslc-modal-layer`, `.modal-note-overlay`.
- Một số Bootstrap modal cũ: `.modal`, `.modal-dialog`.

Các rule cũ nằm rải rác, có rule ở cuối file kéo `.ps-modal-backdrop` về `align-items:flex-start` và `padding-top:80px`, làm modal không còn ở giữa viewport. Khi modal nằm trong vùng table/page có scroll hoặc width riêng, một số modal nhìn như lệch trái.

## Fix
Thêm block CSS cuối `resources/css/pushsale.css`:

`V47 - Modal system normalization`

Nguyên tắc:

1. Overlay luôn `position: fixed; inset: 0`.
2. Overlay luôn flex-center viewport.
3. Radix content luôn `fixed; top:50%; left:50%; transform: translate3d(-50%, -50%, 0)`.
4. Legacy dialog/card luôn là child flex item, `margin:auto`, không còn top/left/transform riêng.
5. Header/footer modal giữ cố định; phần body bên trong scroll.
6. Áp dụng chung cho mọi modal class hiện có, không vá riêng từng page.

- `.ps-modal-backdrop > .ps-source-modal`

- `.legacy-modal-layer > .legacy-modal-dialog`

Không thêm `top`, `left`, `padding-top`, `transform`, `position:absolute` riêng cho từng modal nữa.
